# Reports

This directory is the publication layer for the project.

It should contain the artifacts you would actually cite in a presentation or README:

- dataset profiling outputs
- final-run plots and metrics
- slide-friendly project summaries

## Current contents

- `dataset_analysis_sample/`
  - sampled dataset statistics
  - `DATASET_ANALYSIS.md`
  - class-balance and response figures
- `PRESENTATION.md`
  - slide-oriented summary of the final project state

## What belongs here

- `dataset_analysis/` or `dataset_analysis_sample/` for raw-data inspection
- `final_run/` for the final model analysis
- `PRESENTATION.md` for the condensed presentation version

## Rule of thumb

If a file is meant to be shown to someone else, it belongs in `reports/`.
